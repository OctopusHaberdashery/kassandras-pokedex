# Kassandra's Pokédex

An Android app for tracking a Pokémon card collection: every English set, with card
pictures, every version (Normal / Reverse Holo / Holo / 1st Edition…) and today's
TCGplayer market prices (via tcgcsv.com).

**Install on the tablet:** open this link in Chrome on the tablet, then tap Install:

    https://github.com/<your-username>/kassandras-pokedex/releases/latest/download/KassandrasPokedex.apk

Every time the code changes, GitHub builds a new version automatically
(see the Actions tab) and publishes it under Releases.
